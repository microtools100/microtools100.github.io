How to Use

  • Enter Names: List all participants, one per line
  • Choose Mode: Divide by team count or by team size
  • Generate: Click the button to create random teams
  • Fair Distribution: Uses random shuffling for fair team allocation
  • Multiple Runs: Click Generate again to create different team combinations
  • Flexible Input: Works with names, numbers, items - any text

Tips:

  • Divide by count to ensure equal team distribution
  • Divide by size for specific team requirements
  • Last team may have fewer members when dividing by size
  • Run multiple times to find the best team combination

🔐 Hash Algorithm Information:

  • MD5: 128-bit hash (32 hex chars) - Legacy, use SHA-256+ for security
  • SHA-1: 160-bit hash (40 hex chars) - Deprecated, vulnerable to collisions
  • SHA-256: 256-bit hash (64 hex chars) - Secure, widely used in blockchain
  • SHA-384: 384-bit hash (96 hex chars) - More secure variant
  • SHA-512: 512-bit hash (128 hex chars) - Maximum security

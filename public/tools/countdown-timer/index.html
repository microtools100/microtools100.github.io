    How It Works

    1. Enter the desired time in hours, minutes, and seconds
    2. Click "Start" to begin the countdown
    3. Use "Pause" to temporarily stop the timer
    4. Use "Reset" to clear and start fresh
    5. Alternatively, click a preset button for quick timing
    6. The timer will alert you with sound and notification when finished

    Timer Features

    • Set timers up to 23 hours, 59 minutes, 59 seconds
    • Pause and resume at any time during countdown
    • Quick preset buttons for common durations (1, 5, 10, 30 minutes, 1 hour)
    • Optional audio notification when timer completes
    • Page title updates to show remaining time during countdown
    • Browser tab shows timer status for easy monitoring
    • Works completely offline - no server required

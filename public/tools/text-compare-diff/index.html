    How to Use

    1. Paste the original text into the left field
    2. Paste the modified text into the right field
    3. Select comparison options (ignore case, ignore whitespace)
    4. View the highlighted differences in the results
    5. Check statistics to see the number of changes

    How It Works

    • Side-by-Side Comparison: View both texts with differences highlighted
    • Color Coding: Red for removed, Green for added, Yellow for modified text
    • Ignore Case Option: Treat uppercase and lowercase as identical
    • Ignore Whitespace Option: Normalize spaces for comparison
    • Statistics Display: Shows number of added, removed, and modified lines
    • Real-Time Results: Updates instantly as you paste or modify text

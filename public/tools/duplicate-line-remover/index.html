Options Guide

  • Case Sensitive: When checked, "Apple" and "apple" are treated as different items
  • Trim Whitespace: Removes leading/trailing spaces before comparison
  • Sort Alphabetically: Sorts all unique lines in alphabetical order after removing duplicates
  • Preserves Order: Without sorting, the first occurrence of each line is kept in original order

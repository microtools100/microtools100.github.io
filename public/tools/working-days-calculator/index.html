    How to Use

    1. Select Start Date: Choose the beginning date for your calculation
    2. Select End Date: Choose the ending date for your calculation
    3. Add Holidays (Optional): List holidays in YYYY-MM-DD format, separated by commas
    4. Calculate: Click the Calculate button to see working days breakdown

    How It Works

    • Business Days Count: Counts Monday through Friday only
    • Weekend Exclusion: Automatically excludes Saturdays and Sundays
    • Holiday Support: Optionally exclude custom holidays from the count
    • Detailed Breakdown: Shows working days, weekend days, and total days
    • Both Dates Included: Includes both the start and end dates in calculations
    • Instant Results: Real-time calculation with clear results display

    Frequently Asked Questions

    What counts as a working day?

    A working day is Monday through Friday. Saturday and Sunday are not counted as working days.

    How do I exclude holidays?

    Check the Include Holidays option and add dates in YYYY-MM-DD format (e.g., 2024-01-01). Separate multiple dates with commas.

    Does it count the start and end date?

    Yes, both the start date and end date are included in the working days count.

    Is my data stored?

    No, all processing is done locally in your browser. Your data is never sent to our servers or stored anywhere.

    Can I export the results?

    Yes, you can copy the results using the Copy Results button and paste them into your documents or applications.

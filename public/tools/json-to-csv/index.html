Usage Tips

  • Array of Objects: Best format - each object becomes a row, keys become columns
  • Single Object: Will be converted to a single-row CSV
  • Delimiters: Choose the separator that works with your target application
  • Headers: Uncheck to exclude column names from output
  • Quotes: Fields containing delimiters are automatically quoted
  • Nested Objects: Complex objects are JSON-stringified for the CSV cell

Example:

Input JSON:
[{"name": "John", "age": 30}, {"name": "Jane", "age": 25}]

Output CSV:
name,age
John,30
Jane,25

Generate fake names, emails, phone numbers, addresses, and more for testing. Perfect for development and quality assurance.

How It Works

  1. Select the data type you want to generate (names, emails, phone numbers, addresses, usernames, or dates)
  2. Enter the quantity of records you need (up to 1000 per generation)
  3. Click "Generate Data" to create the fake data
  4. Review the generated data in the output area
  5. Click "Copy All" to copy all generated data to your clipboard
  6. Use the data in your testing, development, or database seeding workflows

Data Types Available

  • Full Names: Realistic first and last name combinations
  • Email Addresses: Valid email format with various domains
  • Phone Numbers: US format with area code and exchange
  • Street Addresses: Complete addresses with street, city, state, and ZIP
  • Usernames: Realistic username variations
  • Birth Dates: Random dates in YYYY-MM-DD format

Quantity Limits & Features:

  • Maximum 1000 records per generation
  • Completely random generation each time
  • No external API calls - all generated locally
  • Privacy assured - no data is stored or sent

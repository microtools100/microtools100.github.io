How to Use

  1. Use the color picker input to select a color or adjust RGB sliders
  2. Enter specific color values in HEX, RGB, or HSL format
  3. View all color formats and copy any value with one click
  4. Explore color harmonies and complementary colors below
  5. Check contrast ratios with the contrast checker
  6. Download your complete color palette

How It Works

  • Color Picker: Click the color input to open your system color picker
  • RGB Sliders: Adjust red, green, and blue values (0-255 each)
  • Format Conversion: Automatically converts between HEX, RGB, HSL, and HSV
  • Shades & Tints: Generates lighter and darker variations of your color
  • Color Harmony: Shows complementary, analogous, and triadic colors
  • Contrast Checker: Calculates WCAG contrast ratios for accessibility

Tips

  • RGB values range from 0 to 255 for each color component
  • HEX codes are 6-character codes starting with # symbol
  • HSL is useful for adjusting lightness and saturation independently
  • WCAG AA standard requires contrast ratio of at least 4.5:1
  • Use contrast checker to ensure your colors are accessible

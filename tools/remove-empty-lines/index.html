    Frequently Asked Questions

    What's the difference between "remove" and "compress" modes?

    Remove deletes all empty lines; compress keeps maximum one blank line between content.

    Will this affect indentation?

    No, whitespace at the beginning of lines (indentation) is preserved.

    Does it remove lines with only spaces?

    Yes, lines with only whitespace are treated as empty lines.

    Can I undo the changes?

    Yes, the original text is preserved; only copy what you want.

    How large a file can I process?

    The tool handles most files; very large files may be slower.

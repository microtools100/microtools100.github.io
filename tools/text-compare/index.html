    How to Use

    1. Paste the original version into the left box (one line per step).
    2. Paste the updated version into the right box (one line per step).
    3. Adjust options like Ignore case or Ignore extra spaces as needed.
    4. Review the results area for added (green), removed (red) and modified (yellow) lines.
    5. Click Copy Results to paste into Excel or your editor.

    How It Works

    Line Matching

    The tool first compares lines between versions to find exact and similar matches using a position-aware similarity metric.

    Word & Character Diff

    For modified lines the tool performs a word-level diff and applies character-level highlighting only within slightly changed words to minimise noise.

    Post-processing

    Adjacent removed and added lines that are similar are merged and displayed as a single modified pair for clarity.

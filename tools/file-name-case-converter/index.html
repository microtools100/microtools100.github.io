    How It Works

    • Lowercase Conversion: All characters to lowercase (myfile.txt)
    • Uppercase Conversion: All characters to uppercase (MYFILE.TXT)
    • Title Case: First letter of each word capitalized (My_File.txt)
    • Extension Preservation: File extensions always preserved correctly
    • Batch Processing: Convert multiple filenames at once
    • Real-time Preview: Instant conversion display

    Frequently Asked Questions

    Will my file extensions be changed?

    No, extensions are always preserved in their original form.

    Does this modify my actual files?

    No, the tool only generates new names; you apply them manually.

    What's the difference between Title Case and Sentence Case?

    Title Case capitalizes first letter of each word; Sentence Case only first letter.

    Can I process many files at once?

    Yes, paste as many filenames as needed, one per line.

    Is my data private?

    Yes, all processing happens in your browser; no data is stored.

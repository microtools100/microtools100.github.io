    Frequently Asked Questions

    Does it remove all duplicate words or just consecutive ones?

    It removes consecutive (adjacent) duplicate words, not all instances throughout text.

    What's the difference between case-sensitive and ignore case?

    Case-sensitive treats "The the" as different; ignore case treats them the same.

    Can I undo the removal?

    Yes, the original text remains; you copy the cleaned version.

    Does it handle punctuation?

    Yes, it intelligently handles words with attached punctuation.

    Is there a file size limit?

    No practical limit; tool processes locally in your browser.

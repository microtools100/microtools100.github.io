    How to Use

    1. Enter Base Name: The primary name for all files
    2. Add Prefix (Optional): Text to add before the name
    3. Add Suffix (Optional): Text to add after the name
    4. Set Number Range: Starting and ending numbers for sequence

    How It Works

    • Prefix Support: Add custom prefix to beginning of each name
    • Suffix Support: Add custom suffix at end before extension
    • Sequential Numbering: Auto-generate number sequences with padding
    • Extension Handling: Preserves original file extensions
    • Batch Generation: Create names for unlimited files
    • Preview Before Apply: Review all names before implementing

    Frequently Asked Questions

    Why should I batch rename files?

    Batch renaming saves time and ensures consistent naming across files.

    What's the difference between prefix and suffix?

    Prefix goes at the beginning, suffix goes at the end of the file name.

    Can I customize the numbering format?

    Yes, choose starting number and padding (001, 01, 1) as needed.

    Is my data stored?

    No, all processing is done locally in your browser.

    Can I preview before renaming?

    Yes, the tool shows all new names before you apply them.
